================================================================================
  GUTTYTECH - ROCKET LEAGUE OPTIMIZER  v25.0.5
================================================================================

App WPF (.exe unico) que otimiza TASystemSettings.ini do Rocket League,
sincroniza o menu de video nos .save e mantem watcher anti-rewrite.

  COMPLETO  -> FPS maximo (texturas 2x2, efeitos no minimo)
  CRIADOR   -> visual pra stream/clip + cortes de FPS
  Remover   -> stock limpo + limpa watcher/modo
  Recuperacao -> permissoes, perfil, boot, save, EAC 30005
  Sistema   -> launch options + ZIP de suporte

--------------------------------------------------------------------------------
 COMO USAR
--------------------------------------------------------------------------------

1. Baixe GuttyTECH_RL.exe na aba Releases do GitHub.
2. Feche o Rocket League.
3. Clique direito -> Executar como administrador (obrigatorio).
4. SmartScreen (1a vez): Mais informacoes -> Executar assim mesmo.
5. Escolha COMPLETO ou CRIADOR.

Pasta de dados/backups (nome estavel):
  %USERPROFILE%\GuttyTECH\RL-Optimizer-v22\

Launch options (copiar no app ou colar na Steam/Epic):
  -nomovie -NOSPLASH -nomansky +mat_antialias 0 -high

--------------------------------------------------------------------------------
 IMPORTANTE
--------------------------------------------------------------------------------

- O INI NAO fica somente-leitura. A protecao e o watcher (PROTECAO).
- Nao mexe no Windows/registro/rede (isso e so o legacy/ antigo).
- MaxFilterBlurSampleCount nunca pode ser 0 (crash). O app usa 2.
